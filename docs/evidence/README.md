# Evidence supplement E

Release 23 October 2026. Open index.html in a browser for the 31 detailed records and all 248 cell notes. Catalogue IDs and evidence IDs have distinct namespaces; catalogue-crosswalk.csv maps them through stable bibliography keys. Source URLs and locators are preserved. The JSON retains the original multilingual working inspection details; the browsable cell notes and crosswalk are in English.

This is a purposive explanatory subset of a 204-entry catalogue, not an exhaustive or random sample. Later additions can inform the narrative without being retroactively coded. Codes index a named property in inspected material and never certify an entire method, all configurations, or XR readiness. No experiments were rerun for this survey. Quantitative JSON files record technical source editions; formal bibliography dates need not equal inspected revision dates.

Annual counts use the bibliographic year: formal publication year for journal/conference records and initial preprint year for preprint-only records. An inspected revision's upload date is not the binning rule. Preprints and later formal versions are merged by work, and the Genie 3 blog is excluded from the 203-paper count. The 2026 bin ends on 23 October.

The manifest hashes each file and records the canonical manuscript-source hash at release. Inspection records preserve version/section boundaries and original source caveats; they do not establish an independent full-text audit of every catalogue entry. Search counts that were not retained have not been reconstructed.
