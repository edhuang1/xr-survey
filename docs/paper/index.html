Visual Generative AI for Extended Reality: A Survey

Guoxi Huang · Aston University

Read PDF ↓Preprints.org ↗Download BibTeX ↓

Abstract

Visual generative models create objects, spatial scenes, time-varying 3D content, and action-conditioned observations for extended reality (XR). Using these outputs requires knowing which viewing, editing, and state-changing operations they support, and which system components supply those operations. This critical narrative review catalogues 204 methods and systems and traces generated outputs into specific XR operations. Four comparison axes organize content units, generative mechanisms, representations, and operating stages; common mathematical definitions clarify conditioning and update rules. An evidence map records eight capability dimensions for a purposively selected subset of 31 methods and systems. The synthesis combines these profiles with source-specific quantitative comparisons and deployment studies, identifying the components, configurations, and endpoints supporting capability claims. Building on paradigm-level comparisons, this analysis distinguishes the evidence needed to generate editable structure, preserve an accepted modification, and respond to tracked input. Visual recall and modification retention require different references, while generation throughput and input-to-display latency describe different parts of the response path. Worked task comparisons explain how these distinctions change the choice between prepared geometry with local rendering and continuing observation generation. We derive task-specific selection criteria and propose matched evaluations of binocular viewing, preview replacement, persistent changes, response scheduling, and physical-space alignment. The resulting framework connects model selection to explicit task requirements and identifies the additional tests needed to assess XR use. The survey homepage is available at https://edhuang1.github.io/xr-survey/.
